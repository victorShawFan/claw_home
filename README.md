# 🦞 Claw Home - 小龙虾 RPG 状态面板

一个 QQ 宠物风格的小龙虾状态可视化界面，让你直观地看到小龙虾在干什么！

## ✨ 特性

- 🎮 **游戏化界面**: QQ宠物/QQ农场风格的可爱UI
- 🦞 **小龙虾状态**: 实时显示当前状态（休息、干活、同步、修复Bug）
- 👥 **多龙虾支持**: 显示主龙虾和子agent龙虾
- 📊 **实时数据**: WebSocket连接，状态实时更新
- 🎨 **可爱动画**: CSS动画让小龙虾活起来

## 🚀 快速开始

```bash
# 本地运行
python3 -m http.server 8080

# 打开浏览器访问
open http://localhost:8080
```

## 🦞 小龙虾状态

| 状态 | 图标 | 描述 |
|------|------|------|
| 休息 😴 | 💤 | 小龙虾在睡觉充电 |
| 干活 💪 | 🔨 | 小龙虾正在努力工作 |
| 同步 🔄 | ☁️ | 小龙虾在同步数据 |
| 修复Bug 🐛 | 🔧 | 小龙虾在苦逼修Bug |
| 思考 🤔 | 💭 | 小龙虾在深度思考 |
| 学习 📚 | 📖 | 小龙虾在学习新技能 |

## 🛠️ 技术栈

- HTML5 + CSS3 + JavaScript
- WebSocket 实时通信
- CSS动画和过渡效果
- 响应式设计

## 🎮 使用说明

1. 打开网页即可看到主小龙虾
2. 状态会实时更新
3. 如果有子agent运行，会自动显示多龙虾
4. 点击小龙虾可以互动！
